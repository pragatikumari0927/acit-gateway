4. Implemented Module Details

C1: Protocol Parser

  • parse_envelope(protocol, envelope) → Mandate
  • Dispatches to parse_ap2/tap/p3p/uap
  • All four share _normalize_to_mandate — best-effort key extraction
  • Supports flat + nested envelope shapes
  • ProtocolParseError.reason_code: unknown_protocol, invalid_envelope, missing_required_field

C3: Vault (SQLite)

  • Vault(db_path) — injected, auto-creates schema
  • Tables: agents, mandates, denylist
  • verify_signature — ES256 JWT via PyJWT + cryptography
  • validate_mandate — checks active, TTL, revoked, denied
  • VaultError.reason_code: unknown_agent, invalid_signature

C4: Prompt Firewall

  • Scans raw dict recursively
  • Rejects forbidden keys: instructions, system, tool_description, developer_message
  • Strips BIDI/ZW chars, checks IDPI phrases + HTML comments
  • Bug: ZW stripping happens before phrase check — doesn't flag ZW presence itself

C2: Catalog Service

  • JSON-file backed (tests/fixtures/catalogs.json)
  • get_catalog(merchant_id), get_item(merchant_id, sku), search(merchant_id, query)
  • Model diverges from design.md spec (see §7 below)

10. Critical Risks & Gaps

🔴 CRITICAL — 5 phases remain, <36 hours to freeze

Phases 5-9 (Policy, Razorpay, Audit, Chaos, Show) are entirely unimplemented. The freeze is 4 Sep 2026. This is the single biggest risk.

🔴 Failing test must be fixed before any commit

test_firewall_detects_zero_width — the Firewall strips ZW chars but doesn't flag their presence. Either change the detection logic or fix the test fixture.

🔴 No FastAPI app exists

src/main.py, src/config.py, src/api/dependencies.py are all empty. There's no HTTP layer, no POST /v1/envelopes, no GET /v1/audit — nothing that can be docker compose up'd.

🔴 CatalogItem model doesn't match design contract

price instead of unit_amount_paise, percent-based discount bounds instead of max_discount_paise. Policy engine can't be built on the current model without reconciliation.

🟡 Vault connection leak

Every Vault method calls self._conn() → sqlite3.connect(). The with self._conn() as conn: pattern auto-commits transactions but does NOT close the connection. 26 ResourceWarnings in tests.

🟡 docker-compose.yml is empty

File exists but has no content. PRD acceptance requires docker compose up.

🟡 Uncommitted work at risk

All of C4 + C2 + their tests + model changes are only in the working tree. A git clean or accidental reset would lose days of work.

🟡 Agent skills bloat

~200+ files across .agents/, .claude/, .grok/ (including a full Python package in .grok/skills/cli-utilities). These add no value to the submission and inflate the repo. Consider .gitignore'ing them.
